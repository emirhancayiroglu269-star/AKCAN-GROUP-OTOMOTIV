# FAZ 15 — KDV / Maliyet / Brüt Kâr
- KDV dahil/hariç satış ayrıştırması.
- Maliyet ve brüt kâr hesabı.
- Brüt kâr marjı.
- İade için ters KDV/maliyet/kâr.
- 0,01 TL toleranslı satış toplamı mutabakatı.

Formül:
Net = KDV dahil toplam / (1 + KDV oranı)
KDV = Toplam - Net
Brüt Kâr = Net Satış - Maliyet
