# FAZ 126 — Dashboard & Favoriler Merkezi

Kullanıcıların ERP ana ekranını kendi çalışma biçimlerine göre kişiselleştirmesi
için merkezi dashboard/favori modeli oluşturuldu.

## Kişiselleştirme
- Favori modüller
- Sık kullanılan işlemler
- Favori raporlar
- Hızlı erişim
- Dashboard kartları
- Kart sıralaması
- Kart boyutu
- Aktif/pasif görünürlük

Ayarlar kullanıcı bazlı tutulur; bir kullanıcının düzeni diğer kullanıcıları
etkilemez.

Production verisi değiştirilmedi.
