# FAZ 128 — Çoklu Dil & Bölgesel Ayarlar Merkezi

ERP'nin farklı dil, ülke ve para birimiyle çalışabilmesi için merkezi
yerelleştirme domain'i oluşturuldu.

## Diller
- Türkçe
- İngilizce
- Arapça

## Para birimleri
- TRY
- USD
- EUR
- GBP

## Bölgesel ayarlar
- Ülke / bölge
- Dil
- Para birimi
- Tarih formatı
- Saat formatı
- Zaman dilimi
- Vergi sistemi

## Çeviri
Ekran metinleri anahtar tabanlı çeviri yapısına bağlanabilir. Dil bulunamazsa
anahtar değerinin kendisi güvenli fallback olarak kullanılır.

Production verisi değiştirilmedi.
