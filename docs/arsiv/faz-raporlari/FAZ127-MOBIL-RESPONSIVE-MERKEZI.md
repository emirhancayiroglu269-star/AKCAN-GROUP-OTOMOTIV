# FAZ 127 — Mobil Uyum & Responsive ERP Merkezi

ERP arayüzünün PC, laptop, tablet ve telefon ekranlarında kullanılabilmesi için
responsive domain temeli oluşturuldu.

## Cihazlar
- Telefon
- Tablet
- Laptop
- PC

## Mobil öncelikli modüller
- Menü
- Dashboard
- Satış
- Cari
- Stok
- Barkod
- Finans
- Bildirimler

## Responsive davranış
Ekran genişliğine göre cihaz tipi ve dashboard kolon sayısı belirlenir.
Mobilde tek kolon, tablette iki kolon, laptopta üç, PC'de dört kolon varsayılanıdır.

Üretim verisi değiştirilmedi; bu faz responsive davranışın domain/config
temelini hazırlar.
