# Akcan Group Otomotiv Web Projesi

Bu proje, `App(1).tsx` dosyasını çalıştırmak için hazırlanmış React + TypeScript + Vite iskeletidir.

## Çalıştırma

1. Node.js 20.19+ kurulu olsun.
2. Terminalde proje klasörüne girin.
3. `npm install`
4. `npm run dev`
5. Tarayıcıda Vite'ın gösterdiği adresi açın (genellikle http://localhost:5173).

## Üretim

`npm run build` komutu ile `dist/` klasörü oluşur. Bu klasör uygun bir web hosting'e yüklenebilir.
